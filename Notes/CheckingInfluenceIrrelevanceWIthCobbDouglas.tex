\section{Purpose}
Let's figure out a check of the influence calculation under Cobb-Douglas.

\section{Objects we need:}

\begin{enumerate}
	\item Influence matrix $\mathbold{\Theta} = (I_N - diag(\underline{\gamma}\mathbold{\Omega})^{-1}diag(1-\underline{\gamma})$ which we use to calculate $\mathbold{D}$ but is distinct from $\mathbold{D}$. This matrix is $N$ x $N$ where $N$ is the number of products.
	\item CPI weight vector $\underline{E}_t$ which contain the weights of each product in CPI. Let's focus on the 2017 values that correspond to the IO data.
\end{enumerate}

\section{The checks:}

We want to know if:

\begin{align*}
	\mathbold{\Theta}'E_{2017} = E_{2017}
\end{align*}

And more generally if:

\begin{align*}
	\mathbold{\Theta}'E_{t} = E_{t}
\end{align*}
